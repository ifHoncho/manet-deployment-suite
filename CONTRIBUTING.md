# Contributing

Thanks for your interest in Trellis.

## Code contributions

Trellis is dual-licensed (see [LICENSING.md](LICENSING.md)), so every line
in the repository must be owned by Eunoia IT Solutions LLC. For that reason,
**pull requests containing code or documentation from outside the project
are not being accepted at this time.** A contributor licence agreement may
be introduced later; this file will be updated when it is.

## Bug reports and ideas

Issues are welcome:

- **Bugs:** include `meshctl doctor` output, your hardware (board, radios,
  kernel version) and the steps to reproduce.
- **Hardware reports:** results from adapters or boards not yet listed in
  [docs/hardware.md](docs/hardware.md) are especially useful.
- **Ideas and design questions:** open an issue describing the problem
  you're trying to solve.

Please don't paste code into issues that you'd like to see merged; describe
the change instead.

## Security

Please don't report security problems in public issues. Email
[security@eunoiacyber.com](mailto:security@eunoiacyber.com) instead.
